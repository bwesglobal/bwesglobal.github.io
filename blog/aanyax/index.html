Introducing AanyaX: The Agentic Harness for Maritime Software

From information access to operational assistance on BOSS

13 June 2026 · 3 min read

Maritime teams have never lacked data. Fleet records, voyage workflows, monitoring feeds, reports, emails, and checklists all contain the signals needed to understand what is happening across an operation. The harder part has always been turning those signals into timely, usable answers.

For years, maritime software has helped teams organize information, search for it, and display it through dashboards and reports. That has been valuable, but it has also left the same burden on the operator: open the system, run the query, review the output, cross-reference the supporting data, and repeat the process again tomorrow.

With AanyaX, Blue Water is introducing a new layer for BOSS: an agentic harness that allows maritime teams to subscribe to or build AI agents that carry out defined operational work across their own fleet data and workflows.

From Information Access to Operational Assistance

AanyaX is designed for the recurring analysis that shipping teams already perform every day and every week. An agent can run on demand or on a schedule, work across a single vessel or an entire fleet, generate a live dashboard, and preserve the context needed for follow-up investigation.

That makes AanyaX different from a simple chat interface. The goal is not only to answer a question in the moment, but to help teams automate repeatable, well-defined work inside the systems they already use.

A fleet overview digest can be prepared before the day begins. A per-vessel agent can review reports and monitoring data, then flag anomalies that deserve attention. Checklist and CORCA status reviews can be summarized across the fleet. Dashboards can be generated around a current operational question rather than a fixed layout created months earlier.

Each of these examples starts with work that is already happening manually. AanyaX turns that work into an agent that can be scheduled, supervised, reviewed, and improved over time.

Built on BOSS

AanyaX is powerful because it is grounded in BOSS. BOSS provides the data, workflows, and operational context that make maritime analysis useful. AanyaX adds an intelligence and automation layer that can repeatedly turn that foundation into timely analysis, dashboards, alerts, and decision support.

BOSS remains the platform clients use to run their operations. AanyaX extends what BOSS can do by making its data and tools available to agents that understand the maritime workflows around them.

This foundation also matters for trust. Because AanyaX operates inside BOSS, agents remain within BOSS guardrails: authenticated user access, client-scoped data, controlled tool access, and auditable run history. The repetitive work can be automated; the decisions remain with the team.

Available First to BOSS Clients

We are opening AanyaX first to existing BOSS clients through a private preview, with pilots already underway. This preview is an opportunity to shape the agent templates that will be most valuable in real operations.

Our ask is straightforward:

Tell us one workflow your team repeats manually every week. We will evaluate whether it should become an AanyaX agent template.

Over the coming weeks, we will share more about scheduled agents, per-vessel agents, and agent-generated dashboards. For now, the direction is clear: maritime software is moving from systems that wait to be queried toward agents that help carry out the work. With AanyaX, that shift begins on BOSS.
