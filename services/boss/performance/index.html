Performance trending

Validated noon data and analysed weather, turned into hull, engine and propeller trends, so hull cleaning, propeller polishing and dry-dock decisions rest on evidence.

Talk to us →

BOSS goes beyond voyage planning and management. The validated noon data combined with analyzed weather is used for deriving insights about vessel performance which can assist vessel operators to take decisions about hull cleaning, propeller polishing, and engine maintenance. Our data-analytics toolkit analyzes the relationships between engine load, fuel consumption, RPM and speed to understand the current and historic vessel performance trend.

Vessel performance curves

BOSS has a dedicated module to analyze the relation between RPM, Speed and Consumption in the given fair weather criteria and given analysis time period. Technical managers use them to schedule dry-docking and hull cleaning, because the curves pinpoint the cause of under-performance.

  • Hull: The engine-RPM vs Speed curves help analyze the hull condition of a vessel. Our dashboard allows the user to track speed through water at any given RPM, over time, to take decisions about hull cleaning.
  • Engine: Engine-load vs fuel consumption curves help analyze engine performance. User-defined KPIs can be set to get alerts when the performance drops below a particular threshold.
  • Propeller: Engine-load vs RPM curves help analyze the propeller condition. BOSS helps predict when the RPM at a given engine load is expected to drop below a set KPI, inorder to plan propeller polishing.
  • Combined: The Speed-FOC curves give an insight about the overall vessel health, reflecting the combined effect of engine, propeller and hull.

Features

  • Choose the analysis period and the fair-weather criteria.
  • Reported data is shown over the fitted curves, so the analysis is transparent.
  • Where fair-weather data is limited, include all days with weather normalisation.
  • Sea margin and warranty tracking, with alerts before a limit is crossed.

Fleet performance

BOSS compares the vessels in a fleet on the same scale for engine, propeller and hull performance. Fuel curves are normalised for each vessel in laden and ballast condition over any period, to find the top, average and worst performers in each class.

The fleet dashboard allows for various levels of abstractions:

  • A dashboard to compare various classes of vessels at a higher level.

  • A dashboard to analyze a class of vessels. Identify the top, average and worst performers in terms of engine, propeller and hull.

  • Vessel-dashboard that links to the vessel performance curves described above and help study the performance trend of a particular vessel over time.

The fleet view shows the overall trend and draws attention to the outliers. From there, the causes of under-performance can be traced, whether crew practice, engine health, or propeller and hull condition, and put right.
