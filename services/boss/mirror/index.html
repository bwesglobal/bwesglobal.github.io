MIRROR noon reporting

Vessel-specific report forms that catch errors on board, and server checks that catch the rest, so every BOSS decision starts from data you can trust.

Talk to us →

MIRROR is a smart noon reporting system that streamlines the flow of data from ship to BOSS. Reporting is fast and error-free, using a standalone form made for each vessel. It covers noon, departure and arrival reports, bunkering, delays and the Statement of Facts (SOF).

How it works

MIRROR validates reports twice: on board, and again when they arrive. Each vessel gets a form with its own limits built in, such as maximum and minimum RPM, engine particulars and the previous ROB. The form checks entries as they are made, so errors are caught on board. When it is complete, the master sends the encoded data and a readable noon report to a dedicated address with one click.

When a report arrives, it is logged automatically and checked again on the server: the noon position against SAT-AIS, reported against analysed weather, speed and RPM consistency, compliance with the voyage plan, performance against warranties, and the ROB.

Any discrepancy goes to a BOSS operator, who resolves it: by asking the master, informing the voyage operator, or updating our hydrodynamic model if it no longer matches what the vessel reports.

The validated data feeds a central voyage database that powers almost every part of BOSS, from voyage management to performance trending and emissions reporting.

Benefits

  • Nothing to install on board. The form works offline in any standard web browser.
  • Error-free reporting, from checks by software and people working together.
  • Feeds BOSS directly, opening the door to every other BOSS service.
  • IMOS compatible, through an API that sends MIRROR data straight to IMOS.
